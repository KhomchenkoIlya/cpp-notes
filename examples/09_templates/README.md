# Block 09: templates

Exactly two experiments support the lecture:

- `mini_generic_library`: a small header-only generic library with positive
  multi-type tests and a real unmet-requirement compile failure;
- `generic_course_audit`: a read-only audit of all 15 course blocks with one
  function-template workflow and two unrelated reporter types.

Each directory is an independent CMake project. Build out of source as shown
in its README.
