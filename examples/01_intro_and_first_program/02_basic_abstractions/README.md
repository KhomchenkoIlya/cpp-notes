# Эксперимент 02 — простые абстракции

Пример использует только конструкции первой лекции:

- `std::string`;
- `std::vector<double>`;
- `std::map<std::string, int>`;
- арифметику и вывод.

Циклы, пользовательские функции, указатели и классы намеренно не используются.

Запуск:

```bash
./run.sh
```

CMake здесь не заменяет компилятор: он описывает цель сборки и организует вызов toolchain.
