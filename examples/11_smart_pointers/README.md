# Block 11 experiments

Ровно два основных эксперимента:

1. `01_ownership_factory_lab` — `unique_ptr`, передача ownership, borrowing API
   и polymorphic Factory Method с owning return type.
2. `02_shared_weak_graph_lab` — реальное shared ownership, strong cycle,
   `weak_ptr`, `lock()` и ownership graph.

Оба проекта используют C++17 и target-based CMake.
