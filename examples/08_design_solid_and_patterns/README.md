# Block 08: design, SOLID, and patterns

Exactly two experiments belong to this block:

1. `01_patterns_lab` starts from direct code and demonstrates Strategy,
   canonical Factory Method, and Observer.
2. `02_course_audit_patterns` audits all 15 real course blocks with replaceable
   audit policies and non-owning result observers.

Each directory is an independent C++17 CMake project. Build out of source as
shown in its README.
