# Практические примеры к конспекту C++

Каталог `examples/` находится в строгом соответствии 1:1 с файлами `lectures/`.

Каждой лекции `lectures/NN_slug.tex` соответствует каталог `examples/NN_slug/`.

В каждом таком каталоге по мере написания лекции должно появиться минимум 1–2 реальные практические вещи:
компилируемая программа, инженерный эксперимент, небольшой CMake-проект, тест, benchmark, sanitizer-эксперимент, исследование assembly или другой исполняемый материал по теме лекции.

Существенный пример из конспекта по возможности должен существовать как реальный файл в репозитории, а не только как листинг в PDF.
