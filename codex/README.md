# Codex workflow files

This directory contains operational metadata for autonomous block-by-block
development.

- `STATE.md` — current project handoff.
- `BLOCK_WORKFLOW.md` — mandatory sequence for one block.
- `PROMPT_TEMPLATE.md` — template used after the user selects one of three
  proposed directions.
- `BLOCK_REPORT_TEMPLATE.md` — final report format expected from Codex.

Detailed project constitution: `../policy.txt`
Short agent contract: `../AGENTS.md`
